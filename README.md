# 名前のピンイン＋

日本人の名前の漢字を普通話の声調付きピンインに変換する学習用アプリです。

公開URL：https://namsan-oss.github.io/name-pinyin-plus/

姓と名を入力し、多音字の読みを意味から選択できます。姓・名それぞれのピンインの先頭を大文字に表示します。入力や選択結果の保存、外部への名前送信は行いません。

## 公開と起動

このリポジトリのルートをGitHub Pagesで配信します。Settings → Pages → Deploy from a branch → main / (root) を選択します。ビルドは不要です。ローカルではHTTPサーバーでこのフォルダを配信してください。

## 対応範囲と制約

14,565の入力文字に対応。一覧は `supported.txt`にあります。名前の網羅的な辞書ではありません。かな、𠮷などの未収録文字は元の文字と「未対応」を表示し、読みを推測しません。

日本語の名前の音訳ではなく、各漢字の中国語辞書に収録された読みを表示します。漢字単位の辞書読みであり、連続発話時の声調変化は扱いません。姓と名の間は `/`、文字間は空白で表示します。中国人の姓の読みを自動優先しません。同じ発音の一般語・姓の辞書項目は大文字小文字を正規化して統合しています。軽声を含む複数の発音は未選択から始まります。

字体はCC-CEDICTの繁簡ペアとOpenCCの新字体対応表を使います。松→松/鬆、谷→谷/穀など、字体が複数ある場合も選択対象です。語や人名の文脈による正字判定はしません。意味だけで人名の慣用読みが確定するわけではありません。

一部の文字の日本語の意味は原文から作成した短い翻訳・要約です。多音字で表示する未翻訳項目2,155件にGoogle翻訳による事前翻訳を追加しました。項目番号と英語原文を照合して発音ごとに同梱しています。通常の単音字には意味を表示しません。自動翻訳の訳文は全件を人手で校閲したものではなく、画面に「自動翻訳」と示し、英語原文を折りたたんで確認できるようにしています。字体ごとに原文が違う5種類（10項目）は個別に翻訳して区別しました。原文の全語義を網羅するものではありません。原文は配布ファイルに残しています。用例は辞書中の参照語を表示します。用例のない項目には創作した例を追加しません。

## 辞書・ライセンス

- **CC-CEDICT / MDBG**：https://www.mdbg.net/chinese/dictionary?page=cedict 。2026-10-10取得、ダウンロードファイルのヘッダーおよび公式ページで **CC BY-SA 4.0** を確認。https://creativecommons.org/licenses/by-sa/4.0/ 。Paul Andrew DenisowskiによるCEDICTを起源とするコミュニティ辞書。`cedict-subset.txt` は単漢字項目の抽出。`data.js` は抽出、発音の統合、日本語訳・要約、字体の統合を行った派生データとして同じ **CC BY-SA 4.0** で配布します。読みごとに `source` に原文を保持しています。
- **OpenCC / BYVoid と貢献者**：https://github.com/BYVoid/OpenCC 。`data/dictionary/JPShinjitaiCharacters.txt` を2026-10-10取得。**Apache License 2.0**。原本を `JPShinjitaiCharacters.txt`、ライセンスを `OPENCC-LICENSE.txt` に同梱。対応先を本アプリの対応辞書に照合して利用。追加の咲→笑、斉→齊、聡→聰はCC-CEDICTの異体字参照に基づきます。

辞書を更新する場合は公式配布ファイルとOpenCC表を入手し、`scripts/build-data.py <cedict.gz> <JPShinjitaiCharacters.txt>` を実行してください。翻訳は `scripts/translations-ja.json` から英語原文の一致を確認して取り込みます。新しい未翻訳の発音は原文を表示します。辞書外の意味を自動生成しません。


## 動作確認

公開前に16項目の自動テストが成功。単音字、多音字切り替え、字体候補、未対応文字、空入力、声調記号、日本語訳と原文の対応、辻の補足読み、声調記号を保持する大文字化を確認しました。

## 音声


多音字と字体候補をすべて選択した後に「発音を聞く」を押します。各文字の選択済みピンインに対応するMP3をWeb Audio APIで順番に再生します。漢字の自動読み判定は使いません。姓と名の間に短い間隔を入れます。一文字ずつの音声の連結であり、自然な連続発話や第三声の変調を再現するものではありません。選択変更・再変換・停止で再生を中止します。

音声素材：davinfifield/mp3-chinese-pinyin-sound https://github.com/davinfifield/mp3-chinese-pinyin-sound 、2026-10-10取得、Unlicense。原本LICENSEをAUDIO-LICENSE.txtに同梱。1627個の数字付きピンインMP3を先頭文字ごとにバイナリにまとめ、audio-manifest.jsの位置・長さから取り出します。数字なしのファイルは声調を推測せず除外。軽声・珍しい音など未収録の読みは「音声未対応」と表示し、別の声調には置換しません。ネットワークでは同梱音声ファイルだけを取得し、入力した名前は送信しません。


ブラウザで音声再生・停止・選択変更時の停止を確認済み。スマホ実機での音声確認は未実施です。
